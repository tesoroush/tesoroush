# The Last Signal / آخرین سیگنال

An original short atmospheric puzzle game for Windows x64.

Download the Windows ZIP from the Releases section, extract it, and run TheLastSignal.exe.

Six rooms, inventory puzzles, a pursuit, original synthesized music, synthetic English radio speech and Persian subtitles.

This is an initial independent game, not a complete remake of 41148.
Validated with 33 automated checks and a graphical Windows EXE smoke test under Wine. Testing on a real Windows installation remains outstanding.
